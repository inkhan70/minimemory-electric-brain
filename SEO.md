## Project summary

**minimemory** is an open-source, offline-first **local AI memory** library for Python applications. It provides private, persistent memory for AI assistants and local LLM applications using SQLite, with deterministic retrieval available without cloud services or mandatory machine-learning packages.

Use minimemory to build a **private AI assistant**, local chatbot memory, RAG application, knowledge base, or personal knowledge management tool. The library supports question-and-answer memory, associative memory, entity relationships, semantic search, knowledge graphs, portable knowledge packs, AI-assisted learning, and local model integrations.

## Relevant use cases

- Local LLM and AI assistant memory
- Privacy-first and offline AI applications
- Python RAG and retrieval-augmented generation projects
- SQLite-backed knowledge bases
- Semantic search and associative recall
- Personal knowledge management and second-brain software
- Ollama and OpenAI-compatible local model integrations
- Android and Termux AI projects
- Portable, exportable AI knowledge packs
- Deterministic memory retrieval without a hosted API
